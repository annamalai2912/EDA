
# Unit 1: Introduction to Data and its Types

## 1. Definition and Importance of Data
Data are the raw facts or figures which are processed and analyzed to create information. In Data Science, understanding the *type* of data dictates the analysis method (e.g., you can calculate the mean of Ratio data, but not Nominal data).

## 2. Classification of Data

### Based on Observation (Time Dimension)
1.  **Cross Sectional Data**: Data collected at a single point in time across multiple subjects (e.g., Census 2020 for all citizens).
2.  **Time Series Data**: Data collected for a single subject over multiple time points (e.g., Stock price of Apple every day for a year).
3.  **Panel Data (Longitudinal)**: Data collected for multiple subjects over multiple time points (e.g., Surveying the same 100 households every year for 10 years).

### Based on Measurement (Scales of Measurement)
1.  **Nominal**: Categories with no order (e.g., Gender, Color). *Mode only.*
2.  **Ordinal**: Categories with order but no fixed interval (e.g., Rank 1st, 2nd, 3rd, Satisfaction Rating). *Median, Percentiles.*
3.  **Interval**: Ordered, fixed intervals, but no true zero (e.g., Temperature in Celsius - 0°C doesn't mean "no heat"). *Mean, Std Dev.*
4.  **Ratio**: Ordered, fixed intervals, true zero exists (e.g., Height, Weight, Salary). *All mathematical operations.*

### Based on Availability
1.  **Primary**: Collected by the researcher directly (Surveys, Experiments).
2.  **Secondary**: Already collected by someone else (Government Census, Kaggle).
3.  **Tertiary**: Compiled from primary and secondary sources (Indexes, Abstracts).

### Based on Structural Form
1.  **Structured**: Organized in rows/columns (Databases, Excel).
2.  **Semi-Structured**: Has tags/markers but no strict schema (JSON, XML).
3.  **Unstructured**: No pre-defined model (Text, Video, Images).

## 3. Sampling Concepts
*   **Population**: The entire group you want to draw conclusions about.
*   **Sample**: A specific group that you will collect data from.
*   **Statistic**: A descriptive measure computed from a sample (e.g., Sample Mean $\bar{x}$).
*   **Parameter**: A descriptive measure computed from a population (e.g., Population Mean $\mu$).

## 4. Frequency Distribution
Frequency distribution is a representation, either in a graphical or tabular format, that displays the number of observations within a given interval.
