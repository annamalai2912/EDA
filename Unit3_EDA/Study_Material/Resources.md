# Study Resources for Exploratory Data Analysis (EDA)

Here are the recommended resources to learn EDA effectively.

## 📚 Books

1.  **"Python for Data Analysis" by Wes McKinney**
    *   Focus: Pandas usage, data wrangling, and basic visualization.
    *   Description: Written by the creator of the pandas library, this is the definitive guide.

2.  **"Exploratory Data Analysis" by John Tukey**
    *   Focus: Mathematical and statistical foundations of EDA.
    *   Description: The classic work that established EDA as a distinct field of statistics.

3.  **"Think Stats" by Allen B. Downey** (Available for free online)
    *   Focus: Probability and statistics for Python programmers.
    *   Description: Clear explanations with practical code examples.

## 🌐 Online Articles & Tutorials

1.  **Pandas Documentation - Visualization**
    *   Link: [https://pandas.pydata.org/pandas-docs/stable/user_guide/visualization.html](https://pandas.pydata.org/pandas-docs/stable/user_guide/visualization.html)
    *   Description: Official guide on using pandas plotting capabilities.

2.  **Seaborn Tutorial**
    *   Link: [https://seaborn.pydata.org/tutorial.html](https://seaborn.pydata.org/tutorial.html)
    *   Description: Excellent visual gallery and tutorials on statistical data visualization.

3.  **Kaggle Learn - Data Visualization**
    *   Link: [https://www.kaggle.com/learn/data-visualization](https://www.kaggle.com/learn/data-visualization)
    *   Description: Interactive course covering line charts, bar charts, heatmaps, scatter plots, and distributions.

4.  **Handling Missing Data (Towards Data Science)**
    *   Link: [https://towardsdatascience.com/how-to-handle-missing-data-8646b18db0d4](https://towardsdatascience.com/how-to-handle-missing-data-8646b18db0d4)
    *   Description: Comprehensive guide on imputation techniques.

## 🎥 Video Resources

1.  **Corey Schafer - Python Pandas Tutorial (YouTube)**
    *   Search: "Corey Schafer Python Pandas"
    *   Description: In-depth, practical tutorials on data analysis with pandas.

2.  **StatQuest with Josh Starmer**
    *   Search: "StatQuest EDA""
    *   Description: Breaks down complex statistical concepts into simple, visual explanations.

## 🛠️ Tools

*   **Jupyter Notebook:** The standard interactive environment for EDA.
*   **Google Colab:** Cloud-based Jupyter notebooks (great for sharing and quick starts).
*   **Tableau Public:** Tool for creating interactive data visualizations without coding (good for final presentation).
